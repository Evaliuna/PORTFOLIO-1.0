# 🌐 Personal Portfolio Website (v1.0)

A clean, minimal and responsive personal portfolio website built using **HTML, CSS, and JavaScript**.  
This project showcases my skills, projects, and learning journey as a CSE student.

---

## 📌 Overview

This portfolio is designed with a **minimal black-and-white theme** to keep it professional and distraction-free.  
It highlights my work, basic skills, and academic projects in a structured layout.

---

## ✨ Features

- Fully responsive design (mobile + desktop)
- Minimal black & white UI design
- Clean navigation layout
- About section
- Skills section
- Projects showcase section
- Contact section
- Lightweight and fast loading

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (basic interactivity)
